## Literal block P1 (experimental)

`p1_blocks` derives from `p1_review` and implements full-axis block products:
`Y = F_s [G0 | ...]` and `Y = [F_r0 | ...] [G0; ...]`.
[Source](active/p1_blocks__697452884c07.c),
[diff against P1 reviewed](../patches/active/p1_blocks.patch),
SHA-256 `697452884c07cc8b22e295ad97ab8eca99e00a97df217c22725fbb8151e7b280`.
It retains the parent's family selection and nonterminal phases; no endpoint
compaction or forced sparsity/thread settings are used. This is a separate
experiment, outside the existing campaign. See [P1_BLOCKS.md](../P1_BLOCKS.md)
for the formulas, validation receipts and comparison command. Full performance
is not measured.

## Historical prepared P1 (lab only)

`p1_prepared` derives from `p1_review` and adds explicit Prepare/Execute/FreePrepared APIs.
[Source](active/p1_prepared__c26e8e4a08c8.c), [diff against P1 reviewed](../patches/active/p1_prepared.patch),
SHA-256 `c26e8e4a08c85158b07722e7088f8b56351b50f2795222c9d1b17b8039b795fe`. Status: experimental, retained for history.
The prepared API and optional adapter were reverted from the checkouts on
2026-11-17. The preserved adapter patch/binary exclude static construction;
use `p1_review` and the default one-shot binary for current measurements.
The Java-only prepared measurements are historical query timings.
See [PREPARED_P1.md](../PREPARED_P1.md).
